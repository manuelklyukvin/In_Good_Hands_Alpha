# In Good Hands — Alpha

Early prototype of my diploma project, before the rewrite into the current In_Good_Hands / In_Good_Hands_Backend repos. Same basic idea - post animals that need a new home, browse a feed of listings - but a much simpler setup: just three modules (app/domain/data) and Firebase (Realtime Database, Storage, Auth) instead of a custom backend.

Kept around for history / to show how the project evolved. The current version has moved to a proper backend, a more modular architecture, and a redesigned UI.

## Stack

- Jetpack Compose
- Hilt for DI
- Firebase (Realtime Database, Storage, Auth)
